Provenance

Why the two cell sizes are comparable

The 43.75 km field is this same ASI array block-averaged 7×7, not a different product. It is drawn at the same screen size so the comparison is of resolution alone. The deck's present raster is 220 cells across a hemisphere disc — close to 45 km a cell — so this is what the deck can currently resolve, using data it does not yet carry.

No-value cells stay no-value: a block is averaged over the cells that carry a reading, and a block with none stays empty rather than becoming zero.

3976 is not 3031

The Arctic grid is EPSG:3413; the Antarctic grid is EPSG:3976, standard parallel 70° S. NASA GIBS publishes Antarctic tiles on EPSG:3031, standard parallel 71° S. Those two differ by 6.6 km at 70° S and 10.0 km at 60° S — more than a cell of anything drawn here. Any surface that carries both must convert.

What is not claimed

Concentration is a retrieval, not a photograph: the ASI algorithm infers it from the 89 GHz polarisation difference, and it is least certain exactly where it is most interesting — thin ice, melt ponds, and the ice edge in summer. The field carries no uncertainty layer here because this frame does not carry one; when it does, it will be drawn rather than described.
